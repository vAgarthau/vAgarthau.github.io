# vAgarthau

An Astro-powered GitHub Pages digital library for Telugu works.

Books live under `content/books/<book-slug>/`. Each book folder contains a `metadata.json` file and one Markdown file per sarga.

```text
content/
  books/
    rukmineesa-vijayamu/
      metadata.json
      sarga-01.md
```

Adding a book should only require a new folder in `content/books` with the same structure.
